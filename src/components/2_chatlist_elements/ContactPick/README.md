# ContactPick

Презентационные компоненты in-column сценария «Новый чат» / «Новый контакт» (как в макете Mobilon One).

Расположение: `2_chatlist_elements/ContactPick/` — по той же схеме, что `ChatFilter`, `ChatItem`.

## Экспорт

- `ContactPickColumn` — flex-колонка на всю высоту слота `#pick` / `#create`
- `ContactPickSubheader` — шапка с «Назад»
- `ContactPickSearchField` — поле поиска
- `ContactPickList` — список с группировкой
- `ContactPickRow`, `ContactPickNewRow`, `ContactPickEmpty`
- `ContactPickInfoBanner` — баннер (например выгрузка Б24)
- `ContactPickFooterButton` — outline-кнопка внизу колонки
